# SpotifyUtils

This is an opinionated collection of utilities for working with Spotify.

## Features

### Automatically add new songs to playlists

This feature supports two uses cases:

1. I have a Lofi master playlist, but new songs from followed artists aren't automatically added.
2. A number of artists don't have a complete discography playlist, so it's really annoying to add
   all their songs to the Lofi master playlist.

This feature will support these by allowing for automatic detection of new songs by whitelisted
artists and automatically adding their new songs to playlist(s).
